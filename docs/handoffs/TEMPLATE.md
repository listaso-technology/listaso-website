# Handoff de tarea

```text
Tarea:
Objetivo:
Estado: complete | partial | blocked
Agente implementador:
Branch:
Commit o estado del working tree:
Archivos reservados:
Archivos modificados:
Validaciones ejecutadas:
Warnings o fallos:
Decisiones tomadas:
Desconocidos:
Riesgos:
Requiere validación Dev:
Siguiente acción recomendada:
```

Antes de comenzar, registrar responsable y archivos reservados en
`docs/WORKLOG.md`. El segundo agente revisa o toma un alcance sin superposición.
