# Listaso Analytics Continuity

Read the route map and verified instrumentation before changing code.

- Inventory IDs without printing secrets, event names, conversions, consent/cookie behavior and route correspondence.
- Prevent duplicate loading and events across layouts, navigation and embeds.
- Preserve UTM/query parameters through approved redirects.
- Record a baseline and comparison plan for 7, 14 and 30 days after cutover.
- Validate safely in preview/debug tooling and report missing account access.

Never create or change IDs, properties, conversions, consent policy or production tags without authorization.
